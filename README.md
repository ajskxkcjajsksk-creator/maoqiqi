## 2. 倍率：标多少扣多少

倍率是流量扣费系数：在 2x 节点上用 1G，扣 2G；在 0.8x 节点上用 1G，只扣 0.8G。目前节点倍率从 **0.8x 到 3.8x**，大多数常用节点在 1x–2x。

这是低价机场里最容易「做文章」的地方，所以我们给自己定了一条硬规矩：

> **节点名里写的倍率 = 实际扣费倍率。**

具体做法：

- 倍率直接写在每个节点的名字里，客户端里就能看到，不用去别处查。
- 每周自动对账：拿每个节点实际上报的原始流量 × 倍率，和每个账号实际被扣的流量逐字节比对。对不上就修，**不留豁免**。

**给你的建议**：订阅后在客户端里看一眼节点名上的倍率，平时手动挑 1x 左右的用，需要 AI 解锁或家宽 IP 时再切到对应的高倍率节点。别开「自动选择」，它只看延迟不看倍率。

延迟与速度没有绝对关系，可以选择对应运营商的节点，在名字上有标注。联通没有标注，是因为联通出海速度本身优秀，基本上都可以使用。也可以连上节点后，在 [fast.com](https://fast.com) 测试单个节点的速度，选择最合适的那个。

## 4. 拼车套餐：独享一个 IP

常规套餐是所有人共用同一批节点。如果你需要**固定、少人用的美国家宽 IP**（比如账号风控严格的 AI 服务、需要稳定登录地的场景），可以买「拼车」套餐：

- **一辆车 = 一个固定的美国家宽 IP**（目前的车是 NTT，以购买页为准），按车限人数（5 席或 3 席），卖满即停售，不会超卖。
- 同车的几条线出口都是同一个 IP，只是入口不同（直连 / 联通 / 移动 / 电信 CN2 等），按自己运营商挑。
- 拼车节点只给同车的人用，与常规套餐不共用。

**怎么确认真的只有几个人在用**（这是我们被问得最多的问题，所以做了三种自证方式）：

1. 客户端里拼车节点的名字末尾写着你自己的席位号，例如 `· 席位 2/3`；
2. 实况页 [catcat7.com/carpool](https://catcat7.com/carpool/) 实时显示每辆车占了几席、每个席位用了多少流量；
3. 每辆车有一个车友群，面板首页领取一次性邀请链接，同车的人都在里面。

## 8. 我们主动屏蔽了什么

家宽和原生 IP 很珍贵，一旦被滥用，整个 IP 的信誉就会变差，所有人都跟着受影响。所以在这些节点上，我们屏蔽了：

- **P2P / BT 下载与做种**
- **加密货币挖矿**
- **发送邮件（SMTP）**——防止被拿去发垃圾邮件
- **ping0.cc 系列 IP 检测站**——社区分析认为它会借 WebRTC 绕过代理获取真实 IP。在我们的节点上打不开 ping0 是预期行为，不是故障。

如果你本来就靠机场跑 BT/PT，我们不适合你。

## 9. 关于 IP 检测分数

用 IPQS 之类的检测站可以查到 IP 分数。

这类分数是按**整段地址和运营商**打的，不是按这个 IP 实际被怎么用。

同一时间我们查了 8 个检测库（Scamalytics、AbuseIPDB、IP2Location 等），发现「AT&T 家宽」「Cox 家宽」以及「Verizon 家宽」由于是美国民用线路，会在各检测网站都判为低风险。

真正决定能不能用的是解锁和速度。如果你在意这个分数，可以换节点名带「AT&T 家宽」、「Cox 家宽」以及「Verizon 家宽」的美国节点。

自己查 IP 可以用 [ipinfo.io](https://ipinfo.io) 或 [iplark.com](https://iplark.com) 等。

附注：日本家宽为日本 So-net 线路。

## 10. 流量重置、换套餐、子账号

**流量重置**：按月循环的套餐，每月在「到期日的那一天」自动重置（通常就是你下单那天的日期），不是每月 1 号。到期日是 29/30/31 号的，统一在每月 28 号重置。

**月中流量用完**：可以在面板里单独购买「重置流量」，价格等于一个月的月付价，不用升级套餐。

**换套餐**：一个账号只有一个套餐，买新的会覆盖旧的。

- 升级（流量更大、周期不更短）：旧套餐的剩余价值自动折抵，结算页直接显示折抵金额。
- 降级、换更短周期：不折抵，建议等到期再换。
- 流量包买流量包：直接叠加。

**同时要两个套餐**：可以开一个[子账号](https://catcat7.com/subaccount)，它有独立的套餐和订阅链接。
